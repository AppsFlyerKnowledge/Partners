> **간단히 보기**: 요약: 이 문서에 나열된 리포트는데이터 락커에서 귀하(마케팅 파트너)가 사용할 수 있습니다. 데이터를 공유하려면 먼저 광고주(앱 소유자)가 본 기사에 설명된 대로 데이터 액세스 권한을 부여해야 합니다.

<div id="data-locker-reports-for-api-partners" />

## 마케팅 파트너를 위한 데이터 락커 리포트

리포트를 받으려면 마케팅 파트너는 다음을 수행해야 합니다.

* 광고주가 <Anchor target="_blank" href="/partners/ko/docs/access-to-aggregated-analytics-tools-for-api-partners#grant-permission-to-a-partner">집계된 분석 리포트에 액세스</Anchor>할 수 있는 권한을 제공했는지 확인합니다.
* <Anchor target="_blank" href="/partners/ko/docs/data-locker-for-partners#set-up-data-locker">데이터 락커를 설정합니다</Anchor>. **참고**:

마케팅 파트너가 사용할 수 있는 리포트는 다음과 같습니다.

리포트는 h=23 폴더로 스트리밍됩니다.
