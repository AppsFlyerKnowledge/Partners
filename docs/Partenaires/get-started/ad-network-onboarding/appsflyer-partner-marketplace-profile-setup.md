> **En bref** : créez une page de profil du Marketplace des partenaires contenant des informations sur votre entreprise, services et solutions.

Le Marketplace des partenaires AppsFlyer est l'endroit où les annonceurs peuvent trouver de nouveaux réseaux publicitaires et de nouvelles plateformes de marketing avec qui travailler. Il propose toutes les informations qui permet aux annonceurs de faire un choix éclairé.

Pour modifier la page de votre Marketplace des partenaires : dans le tableau de bord AppsFlyer, cliquez sur le menu déroulant en haut à droite, puis sur **Configurer le partenaire**.

**Remarque** : Certains champs sont obligatoires, le profil ne pourra être sauvegardé ou publié s'ils ne sont pas remplis.

## Infos sur l'entreprise

Dans cette section, vous pouvez ajouter et modifier les infos sur votre entreprise.

![partenaire](https://files.readme.io/30d89cac0f595b2202f4125b111b501a901f0883a9f241dc3ded73a01ab0ee2d-16157066059153.png)

Pour voir à quoi ressemble votre page dans le marketplace (sans possibilité de navigation), cliquez sur **Voir la page publiée**.

Pour visualiser votre brouillon enregistré, cliquez sur **Aperçu du brouillon**.

<div id="general" />

### Général

Les informations contenues dans cette section sont dynamiques et reposent sur votre configuration et votre activité dans AppsFlyer :

* Type de partenaire
* <Anchor target="_blank" href="/partners/fr/docs/data-richness-score-for-ad-networks">Richesse des données</Anchor>
* Capacités d'intégration
* Catégories et sous-catégories de secteur
* Géo de votre trafic

<div id="profile" />

### Profil

Ajoutez ou modifiez les détails de votre entreprise (comme le logo de l'entreprise (obligatoire), la description (obligatoire), le site web, les langues prises en charge, etc.)

Cette courte description s'affiche dans votre aperçu dans le cadre de la recherche de marketplace des partenaires.

La description complète s'affiche sur votre page du marketplace des partenaires.

Nous vous recommandons de remplir tous les champs pour fournir le plus d'informations possible et rendre votre page de marketplace des partenaires plus attrayante pour les clients.

### Contacts

Sélectionnez l'un des moyens suivants pour que les annonceurs puissent <Anchor target="_blank" href="/marketers/fr/docs/partner-integrations#contacter-le-partenaire">vous contacter</Anchor> via le marketplace des partenaires :

* **Contact commercial :** saisissez les coordonnées (e-mail requis) qui sera indiqué dans l'e-mail de présentation que AppsFlyer enverra au nom de l'annonceur. Cet e-mail est envoyé lorsque l'annonceur clique sur **Me présenter** sur la page infos de votre marketplace.  
  **Remarque :** Si aucune coordonnée n'est fournie, le bouton **Me présenter** sur le marketplace est grisé.
* **Lien vers votre page d'accueil :** vous pouvez choisir d'envoyer les utilisateurs directement vers une page d'accueil. En sélectionnant cette option, les annonceurs verront le bouton **Contacter le partenaire** au lieu du bouton **Me présenter**, et en cliquant dessus, ils seront dirigés vers votre URL.  
  **Astuce :** ajoutez un paramètre UTM à votre lien pour vos propres actions de suivi.

## Votre offre

Dans cette section, ajoutez les détails des services que vous proposez. Nous recommandons d'ajouter autant d'informations que possible pour faciliter la recherche dans le marketplace des partenaires.

[![partenaire](https://files.readme.io/24be219c61499c8a404bc72eaa070c23f273aeb4026fdf8199ed4cc86bb4106b-16157082772625.png)](https://files.readme.io/24be219c61499c8a404bc72eaa070c23f273aeb4026fdf8199ed4cc86bb4106b-16157082772625.png)

Pour ajouter ou modifier les informations sur vos services, cliquez sur le nom du service.

<div id="overview" />

### Présentation

* Sélectionnez jusqu'à 3 services dans la liste.
* Saisissez les mots-clés de la recherche. Il s'agit des mots-clés que les clients peuvent entrer dans la barre de recherche du marketplace des partenaires.
* Saisissez les points forts de votre service sous forme de liste à puces.
* Fournissez une description détaillée de votre offre.

<div id="characteristics" />

### Caractéristiques

Donnez les informations sur vos services. Sélectionnez toutes les options qui peuvent s'appliquer (elles sont utilisées comme filtres dans le marketplace des partenaires) :

* Types de tarification. ex. CPA, forfaitaire, par abonnement...
* Types de publicités pris en charge. ex. Bannière, Video, jeu.
* Types de trafic. Incitatif, non incitatif, préchargé.
* Types de services Pris en charge ou en libre-service.
* Plateformes prises en charge
* Normes de conformité.

<div id="sales" />

### Ventes

Saisissez les infos tarifaires du service :

* Lien vers les conditions d'utilisation du service
* Tarif minimum du service

<div id="marketing-collateral" />

### Matériel marketing

Ajoutez les infos marketing sur l'offre :

* Images
* Kit marketing
* Témoignages des clients
* Vidéo
