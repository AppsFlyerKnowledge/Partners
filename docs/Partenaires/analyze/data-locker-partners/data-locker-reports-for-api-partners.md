> **En bref** : les partenaires marketing (vous) peuvent accéder aux rapports listés dans cet article depuis leur Data Locker.Avant que nous puissions partager les données avec vous, l'annonceur (propriétaire de l'app) doit vous accorder l'accès aux données, comme indiqué dans cet article.

## Rapports Data Locker pour les partenaires marketing

Pour obtenir des rapports, le partenaire marketing doit

* Assurez-vous que l'annonceur vous a donné l'autorisation d'<Anchor target="_blank" href="/partners/fr/docs/access-to-aggregated-analytics-tools-for-api-partners#grant-permission-to-a-partner">accéder aux rapports d'analyse agrégés</Anchor>.
* <Anchor target="_blank" href="/partners/fr/docs/data-locker-for-partners#set-up-data-locker">Configurez Data Locker.</Anchor>. **Remarque** : passez les étapes 3-4.

Les rapports suivants sont mis à la disposition des partenaires commerciaux :

* <Anchor target="_blank" href="/marketers/fr/docs/cohort-analytics-via-data-locker">Cohorte unifiée</Anchor>
* <Anchor target="_blank" href="/marketers/fr/docs/cohort-analytics-via-data-locker">Cohortes d'acquisition d'utilisateurs</Anchor>
* <Anchor target="_blank" href="/marketers/fr/docs/cohort-analytics-via-data-locker">Retargeting des cohortes</Anchor>
* [Beta] Des rapports versionnés sont également disponibles, avec des données actualisées.

Les rapports sont diffusés dans le dossier h=23.
