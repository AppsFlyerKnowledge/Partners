> **At a glance:** Learn the differences between an Agency account and an Ad Network integration, and the advantages of each.

## Agency account

<span id="b6fb9285-2105-489b-8048-548ba5ce0705"></span>AppsFlyer Agency Solution enables you to manage all your advertiser's performance under one universal dashboard!

Agency Account Key Features:

* Access to real-time analytics, once our SDK is embedded within the app.
* Access to all data, including in-app events, generated by the agency.
* Self-serve dashboard for generating AppsFlyer attribution links which enable the agency to work with 1500+ different Ad Networks.

Click this link to learn more about how to set up an <Anchor target="_blank" href="/partners/zh/docs/about-agency-accounts">Agency Account</Anchor>.

## Ad network integration

As an AppsFlyer integrated partner, your name and logo are presented on the AppsFlyer website. The integration enables you to receive information via postbacks. You'll get an ad network login that holds install and postback information.

> 📘 **Note**
>
> <span id="3374412f-c633-465b-9ca9-657ee4be30f3"></span>Ad networks don’t have access to the Events Dashboard and can see in-app events on Overview Dashboard only after the advertiser enables the **Access aggregate in-app events data** <Anchor target="_blank" href="/marketers/zh/docs/set-up-an-integrated-partner#permissions-tab">ad network permission</Anchor>. However, you can export in-app event-related data from the <Anchor target="_blank" href="/partners/zh/docs/test-marketer-campaign-integration-with-the-ad-network#verifying-postback-data">In-app events postback</Anchor> report.

See <Anchor target="_blank" href="/partners/zh/docs/getting-started-onboarding-guide-for-ad-networks#第一部分对接与测试">Ad Network Integration Guide</Anchor>.

To proceed, provide your Click URL, Postback URL, and company logo (a 200x50 transparent PNG).
