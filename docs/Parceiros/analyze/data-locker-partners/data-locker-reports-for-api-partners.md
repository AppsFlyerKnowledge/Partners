> **Visão geral**: os relatórios listados neste artigo estão disponíveis para você (parceiros de marketing) em seu Data Locker. Antes de podermos compartilhar os dados com você, o anunciante (proprietário do aplicativo) deve lhe conceder acesso aos dados conforme detalhado neste artigo.

## Relatórios do Data Locker para parceiros de marketing

Para obter relatórios para você, o parceiro de marketing deve:

* Certifique-se de que o anunciante lhe deu permissão para <Anchor target="_blank" href="/partners/pt/docs/access-to-aggregated-analytics-tools-for-api-partners#grant-permission-to-a-partner">acessar os relatórios de análise agregados</Anchor>.
* <Anchor target="_blank" href="/partners/pt/docs/data-locker-for-partners#set-up-data-locker">Configure o Data Locker</Anchor>. **Observação**: pule as etapas 3 a 4.

Os seguintes relatórios estão disponíveis para parceiros de marketing:

* <Anchor target="_blank" href="/marketers/pt/docs/cohort-analytics-via-data-locker">Coorte unificada</Anchor> (diário)
* <Anchor target="_blank" href="/marketers/pt/docs/cohort-analytics-via-data-locker">Aquisição de usuários de coorte</Anchor> (diário)
* <Anchor target="_blank" href="/marketers/pt/docs/cohort-analytics-via-data-locker">Retargeting de coorte</Anchor>
* <Anchor target="_blank" href="/marketers/pt/docs/advanced-aggregated-reports-in-data-locker">Relatórios agregados avançados (com versão)</Anchor> também estão disponíveis, com dados mais atualizados.

Os relatórios são transmitidos para a pasta h=23.
