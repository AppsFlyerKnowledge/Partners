> **Visão geral:** conheça as diferenças entre uma conta de agência e uma integração de ad networks e as vantagens de cada uma delas.

<div id="agency-account" />

## Conta de agência

A solução para agências da <span id="b6fb9285-2105-489b-8048-548ba5ce0705"></span>AppsFlyer permite que você gerencie todo o desempenho do seu anunciante a partir de um único dashboard universal!

Principais características das contas de agência:

* Acesso a análises em tempo real, assim que nosso SDK for incorporado ao aplicativo.
* Acesso a todos os dados, incluindo eventos in-app, gerados pela agência.
* Painel de autoatendimento para gerar links de atribuição AppsFlyer que permitem que a agência trabalhe com mais de 1500 <span id="3374412f-c633-465b-9ca9-657ee4be30f3"></span>ad networks diferentes.

Clique neste link para saber mais sobre como definir uma <Anchor target="_blank" href="/partners/pt/docs/about-agency-accounts">conta de agência</Anchor>.

<div id="ad-network-integration" />

## Integração com ad networks

Como parceiro integrado da AppsFlyer, seu nome e logotipo são apresentados no site da AppsFlyer. A integração com a AppsFlyer como uma ad network permite que você receba informações via postbacks. Como parceiro integrado da AppsFlyer, você recebe um login na ad network que contém informações de instalação e postback.

<div id="note" />

> 📘 **Nota**
>
> As ad networks não têm acesso ao dashboard de eventos e só podem ver eventos in-app no Dashboard Overview depois que o anunciante habilitar a **permissão da ad network de acessar dados agregados de eventos in-app** <Anchor target="_blank" href="/marketers/pt/docs/set-up-an-integrated-partner#permissions-tab">permissão da ad network</Anchor>. No entanto, você pode exportar dados relacionados a eventos in-app do relatório <Anchor target="_blank" href="/partners/pt/docs/test-marketer-campaign-integration-with-the-ad-network#verificação-de-dados-de-postback">de postback de eventos in-app</Anchor>.

Consulte o Guia de integração de ad networks.

Para continuar, forneça seu URL de clique, URL de postback e logotipo da empresa (um PNG transparente de 200x50).
