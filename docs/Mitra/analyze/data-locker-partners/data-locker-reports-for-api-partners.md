> **Sekilas**: Laporan yang tercantum dalam artikel ini tersedia untuk Anda (mitra pemasaran) di Data Locker Anda. Sebelum kami dapat membagikan data kepada Anda, pemasang iklan (pemilik aplikasi) harus memberi Anda akses data sebagaimana dijelaskan secara rinci dalam artikel ini.

## Laporan Data Locker untuk mitra pemasaran

Untuk mendapatkan laporan Anda, mitra pemasaran harus:

* Pastikan bahwa pemasang iklan telah memberi Anda izin untuk <Anchor target="_blank" href="/partners/id/docs/access-to-aggregated-analytics-tools-for-api-partners#grant-permission-to-a-partner">mengakses Pelaporan analitik gabungan</Anchor>.
* <Anchor target="_blank" href="/partners/id/docs/data-locker-for-partners#set-up-data-locker">Pengaturan Data Locker</Anchor>. **Catatan**: Lewati langkah 3-4.

Laporan berikut tersedia untuk mitra pemasaran:

* <Anchor target="_blank" href="/marketers/id/docs/cohort-analytics-via-data-locker">Kelompok terpadu</Anchor>
* <Anchor target="_blank" href="/marketers/id/docs/cohort-analytics-via-data-locker">Akuisisi pengguna kelompok</Anchor>
* <Anchor target="_blank" href="/marketers/id/docs/cohort-analytics-via-data-locker">Penargetan ulang kelompok</Anchor>
* [Beta] Laporan berversi juga tersedia, dengan keaktualan data yang ditingkatkan.

Laporan di-streaming ke folder h=23.

<Accordion title="Spesifikasi dan batasan">

| Spesifikasi | Catatan |

Artinya, event pendapatan iklan di laporan hari Senin terjadi pada hari Sabtu.</li><li>[Beta] Laporan berversi biasanya tersedia pada pukul 06.00 UTC.</li></ul> |
