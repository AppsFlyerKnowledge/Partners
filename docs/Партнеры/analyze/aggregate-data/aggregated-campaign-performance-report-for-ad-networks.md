> **Краткий обзор**: Краткий обзор. Рекламные сети загружают агрегированный отчет об эффективности (он же Когортный отчет) в свои системы бизнес-аналитики для расчета показателей эффективности кампаний, таких как удержание пользователей на 7-й день.

## Агрегированный отчет об эффективности кампаний

Этот отчет содержит данные об эффективности кампаний, включая количество уникальных пользователей, совершивших те или иные события. Вы (рекламная сеть) используете эти данные в своих системах бизнес-аналитики для расчета показателей эффективности кампаний в контексте KPI рекламодателя. Отчет доступен ежедневно через <Anchor target="_blank" href="/partners/ru/docs/data-locker-for-partners">Data Locker для партнеров</Anchor>

**Зачем нужен этот отчет?**

До выхода iOS 14.5 постбэки, отправляемые вам AppsFlyer, содержали достаточно данных для расчета метрик событий по уникальным пользователям.

После выхода iOS 14.5 и внедрения рекламодателями агрегированной атрибуции, основанной на дифференцированной конфиденциальности (AAP), постбэки по пользователям, не давшим согласия, не содержат идентификаторов пользователей. Без идентификаторов нельзя рассчитать метрики событий по уникальным пользователям, например, удержание клиентов на 7-й день. Отсутствие метрик по уникальным пользователям ограничивает возможности оптимизации кампаний и определения общих с рекламодателями целей по удержанию пользователей.

**Какие данные есть в отчете?**

Данные предоставляются с максимально возможной детализацией на основе переданных показателей и содержат следующие метрики эффективности:

* Доход
* Сколько раз выполнялось данное событие
* Кол-во уникальных пользователей, совершивших событие
* <Anchor target="_blank" href="https://docs.google.com/spreadsheets/d/e/2PACX-1vS89RlkFIss7uARroJcOcX1rU6gUmZ2ySYwfTprg9GaA2BYnvDPVqWmOicea1wrBnNuGgEuLPwzL_ac/pub?gid=0&single=true&output=csv">Пример отчета</Anchor>

**Как получить отчет?**

* Предоставляется через Data Locker для партнеров. Отчет обновляется <Anchor target="_blank" href="/marketers/ru/docs/about-data-freshness-and-timezone-support#daily">ежедневно по времени часового пояса UTC</Anchor>.
* Чтобы мы могли предоставлять вам данные, рекламодатели должны [дать разрешение](/docs/aggregated-campaign-performance-report-for-ad-networks#permission-to-get-aggregated-performance-data) на дэшборде.

<div id="bi-developer-considerations" />

<Accordion title="Информация для разработчиков систем бизнес-аналитики">

**Объём данных в отчёте**

Отчет содержит данные атрибуции пользователей, установки, реатрибуции и повторные вовлечения, а также связанные с ними внутренние события приложений.

В процессе потребления данных необходимо реализовать логику разделения данных по типам кампаний. То есть на атрибуцию пользователей (установки) и ретаргетинг (повторные вовлечения). Для этого используйте поля conversion\_type и is\_primary\_attribution. См. <Anchor target="_blank" href="/marketers/ru/docs/resolve-retargeting-double-attribution">Двойная атрибуция событий ретаргетинга.</Anchor>

**Соображения на уровне поля**

* Чтобы упростить расчет метрик удержания пользователей, используйте дни после атрибуции.
* Расчет уникальных пользователей с помощью таких показателей, как название кампании и идентификатор кампании: Если вы можете не принимать в расчет детализацию по названию кампании, вы можете суммировать количество уникальных записей по ID кампании, и метрики будут корректными.
* Вы можете агрегировать данные по полям иерархии кампаний.
* Во внутренних событиях приложениях используется имя события рекламодателя, и они не сопоставлены с вашими именами событий. Попросите рекламодателя предоставить вам сопоставления или найдите их на дэшборде. <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#g-in-app-event-postback-configuration">Сопоставление партнерских внутренних событий приложения</Anchor>.
* Доход в долларах США рассчитывается по валютному курсу на день события.
* События дохода от рекламы включены в случае доступности, но с задержкой по времени до 5 дней.

**Общие соображения**

* Обновление данных: ежедневно в 08:00 UTC. Обновление данных: Данные записываются в папку h=23 в Data Locker.
* Доступные данные — это данные атрибуции пути пользователя, атрибутируемые AppsFlyer. Это значит, что данные SKAdNetwork, передаваемые в постбэках iOS, в этот набор данных не входят.
* Данные содержатся в файлах по нескольким приложениям. Идентифицировать приложения можно по полю app\_id.
* Если вы не получили данные по определенному приложению, убедитесь, что рекламодатель предоставил вам необходимые разрешения.

</Accordion>

<div id="retention-report-considerations" />

<Accordion title="Примечания по отчетам об удержании пользователей">

Чтобы создать метрики удержания пользователей, например, удержание пользователей на 7-й день, настройте фильтры по следующим полям:

* days\_post\_install=7
* event\_name=af\_session
* conversion\_type, если требуется
* Чтобы исключить <Anchor target="_blank" href="/marketers/ru/docs/resolve-retargeting-double-attribution">дублирующиеся события ретаргетинга</Anchor>, выберите is\_primary\_attribution=true или используйте conversion\_type, чтобы ограничить набор данных установками (installs).
* Сгруппировать по: кампания и другие показатели.
* Сумма: unique\_users\_count

Добавляя и удаляя показатели, вы можете получить метрики с разным уровнем детализации.

</Accordion>

## Разрешения

Вы (рекламная сеть) должны попросить рекламодателя предоставить вам перечисленные здесь разрешения. Рекламодатель должен выполнить эту процедуру один раз для каждого приложения.

<div id="permission-to-get-aggregated-performance-data" />

<Accordion title="Разрешение получать агрегированные данные об эффективности">

Рекламные сети, назначенные (активированные) агентствами: агентство не может выдать разрешение. Агентство должно попросить рекламодателя предоставить им разрешение.

**Чтобы разрешить рекламной сети получать агрегированные данные об эффективности:**

1. В AppsFlyer в боковом меню выберите **Сотрудничество** > Интегрированные партнеры.
2. Найдите партнера и выберите его.
3. Нажмите **Настроить интеграцию**. Вы будете перенаправлены на страницу настройки интеграции.
4. Убедитесь, что переключатель **Активировать партнера** включен. Если нет, данные не передаются.
5. Перейдите на вкладку **Разрешения**.
6. Включите следующие разрешения для рекламных сетей:
   * **Доступ к агрегированным данным о конверсиях**.
   * **Доступ к агрегированным данным по внутренним событиям приложения**.
   * **Доступ к агрегированным данным о доходах**.
7. Нажмите Сохранить разрешения.
8. Сообщите рекламной сети, что разрешения предоставлены.
9. Если у вас несколько приложений, повторите процедуру по каждому приложению, для которого настроена интеграция с партнером.

</Accordion>
