> **Кратко:** Повысьте качество данных, которые вы предоставляете рекламодателям, с помощью оценки полноты данных AppsFlyer.

Качество данных, которые рекламодатели получают от рекламных сетей, на которых они проводят свои кампании, может играть важную роль при принятии маркетинговых решений.

Данные, предоставляемые разными рекламными сетями, различаются по охвату, точности и детализации. Неполные и неточные данные снижают возможности рекламодателей анализировать и оптимизировать эффективность своих кампаний в AppsFlyer.

Оценка полноты данных — это метрика, предоставляемая AppsFlyer, которая показывает, насколько полными являются данные рекламных сетей. Эта оценка доступна всем рекламодателям, поэтому они могут понимать возможности каждой сети и качество ее данных, а также принимать обоснованные бизнес-решения.

Чтобы получить максимальную оценку, рекламные сети должны устранить имеющиеся у них пробелы в данных.

## Оценка полноты данных

**Чтобы увидеть показатель насыщенности данных:**

1. Войдите в свою учетную запись.
2. Откройте дэшборд любого приложения, которым вы управляете.
3. Нажмите **Активные интеграции** на левой боковой панели.  
   Индикатор показателя отображается под названием вашей сети.

   ![integrated-partners-data-richness.png](https://files.readme.io/ee68f4ba63ef4e27292ed6b857e2cd05e4d83f8ba65a80655d1bf8b63df94f5f-360009360018.png)

Рекламодатели могут видеть оценку полноты данных (низкая, средняя или высокая) для каждой рекламной сети, у которой есть интеграция с AppsFlyer.

<div id="included-data" />

### Включенные данные

Чтобы увидеть показатель по каждой категории данных, входящей в него, наведите указатель на индикатор. Открывается всплывающее окно, в котором отображаются итоговая оценка и группы данных: данные кампании, данные рекламного объявления и данные паблишера.

Чтобы получить высокую оценку, рекламная сеть должна передавать следующие параметры по всем кликам и просмотрам:

* Данные кампаний:
  * Строка
  * Доступно только в <Anchor target="_blank" href="/marketers/ru/docs/about-data-locker-advanced-reports">расширенных отчётах</Anchor>.
* Данные рекламного объявления:  
  * идентификатор группы объявлений (adset);
  * название группы объявлений;
  * Идентификатор
  * Название рекламного объявления
  * Тип объявления
* Данные издателя
  * Тип устройства: xiaomi-Redmi Note 8
  * ID субсайта
  * канал.

<div id="data-threshold" />

### Порог данных

* Оценка рассчитывается еженедельно и может повышаться или снижаться в зависимости от полноты перечисленных выше параметров.
* Чтобы оценка была рассчитана, требуется минимальное количество конверсий (установок, реатрибуций, повторных вовлечений). Если у сети меньше конверсий, чем минимально требуется в течение данной недели, то на следующей неделе индикатор оценки будет отключен, а категории данных не будут отображаться.
