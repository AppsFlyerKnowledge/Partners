## **Необходимые условия:**

* Прежде чем вы сможете управлять ссылками атрибуции и постбэками, вам необходимо иметь учетные данные для входа (имя пользователя и пароль) в AppsFlyer. Чтобы <Anchor target="_blank" href="/partners/ru/docs/getting-started-onboarding-guide-for-ad-networks">создать аккаунт партнера</Anchor>, попросите клиента AppsFlyer (рекламодателя) <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#приглашайте-новых-партнёров-в-appsflyer">пригласить вас</Anchor>.
* Управление ссылками атрибуции и постбэками по умолчанию доступно только партнерам, присоединившимся после 1 февраля 2022 года.
* Убедитесь, что ваши серверы готовы получать постбэки, проверив следующее:
  * Внесите <Anchor target="_blank" href="/marketers/ru/docs/appsflyer-server-ip-address-ranges-allowlisting">IP-адреса</Anchor> серверов AppsFlyer в список разрешенных в ваших брандмауэрах и системах безопасности, чтобы обеспечить связь с вашими конечными точками.
  * Версии TLS: TLS 1.1, TLS 1.2+ с <Anchor target="_blank" href="/marketers/ru/docs/appsflyer-https-ssl-encryption-policy-support#исходящие-сообщения-appsflyer-в-роли-клиента">указанными шифрами.</Anchor>
  * Порты:  80, 443

## Доступ к управлению интеграцией

1. Войдите в свой аккаунт партнера в AppsFlyer.
2. Нажмите раскрывающееся меню в правом верхнем углу > **Управление постбэками**.

<div id="attribution-link" />

## Ссылка атрибуции

Ссылка атрибуции — наиболее важная часть вашей интеграции. Ссылки атрибуции используются для уведомления AppsFlyer о взаимодействии пользователя с рекламой. Ссылки атрибуции размещаются в объявлениях, поэтому когда пользователь нажимает на объявление, он нажимает на ссылку атрибуции.

Завершение настройки ссылки атрибуции является обязательным.

**Чтобы настроить ссылку атрибуции:**

1. На вкладке **Ссылка атрибуции** добавьте параметры, которые будут включены в ссылку:

   * **Имя параметра**: Экранное имя параметра AppsFlyer.
   * **Ваш макрос**: добавьте макрос, который заполняет параметры значениями.
   * **Включить**: установите флажок, чтобы включить параметр в ссылку.

   <div id="important" />

   > 🚧 **Важно!**
   >
   > * Добавьте параметры, связанные с кампанией и объявлениями, чтобы получить более надежные данные об эффективности кампании.
   > * **Идентификатор сайта** — обязательный параметр.
   > * Рекламодатели используют эту ссылку как основу для интеграции конкретного приложения и могут добавлять к ней дополнительные параметры.
   > * Идентификатор приложения, продолжительность окна атрибуции и ваш идентификатор партнера добавляются в ссылку автоматически, и вам не нужно добавлять их в этот шаблон.

2. **[Необязательно]** Добавьте свои параметры, которые не предоставляются AppsFlyer.
3. Используйте предварительный просмотр ссылки, чтобы проверить, что все настроено правильно.
4. Нажмите **Сохранить**.

<Anchor target="_blank" href="/marketers/ru/docs/about-link-structure-and-parameters">Подробнее о ссылках атрибуции и доступных параметрах</Anchor>.

## Постбэк по умолчанию

Постбэки — это URL-адреса, содержащие макросы, заполняемые AppsFlyer и отправляемые на ваши серверы в режиме реального времени после каждой конверсии (либо в вашей сети, либо в других сетях — в зависимости от вашей конфигурации).

**Чтобы настроить постбэк по умолчанию:**

1. Введите **адреса конечных точек.** Это конечные точки, на которые отправляются постбэки. Введите действительные URL-адреса для установок и/или внутренних событий приложения. Чтобы активировать интеграцию, требуется как минимум URL-адрес для постбэка об установке.
2. Добавьте параметры в постбэк:

   * **Имя параметра**: Экранное имя параметра AppsFlyer.
   * **Получаемый параметр**: соответствующий получаемый параметр на вашей стороне
   * **Значение параметра** (доступно для некоторых параметров): Выберите формат значения. Например, «true/false» или «1/0» для логических значений.
   * **Установка**: установите флажок, чтобы включить параметр в постбэк об установке
   * **Внутреннее событие**: установите флажок, чтобы включить параметр в постбэк о внутреннем событии приложения.

   <Anchor target="_blank" href="/partners/ru/docs/postback-macros-for-ad-networks">Полный список макросов для постбэков</Anchor>

   <div id="important-1" />

   > 🚧 **Важно!**
   >
   > * Чтобы иметь возможность различать постбэки для легитимных событий и постбэки с отказом, настройте <Anchor target="_blank" href="/partners/ru/docs/postback-macros-for-ad-networks#макросы-установки-внутренние-события-приложения-и-отклоненные-события">макросы для постбэков с отказом</Anchor>.
   > * Чтобы включить постбэки с отказом об установках или внутренних событиях, добавьте следующие параметры в шаблон постбэков по умолчанию:
   >   * `отклонено`
   >   * `причина блокировки`
   >   * `подпричина блокировки`
   >   * `blocked-reason-value`  
   >     **Примечание.** Если включены постбэки для режима расширенной конфиденциальности, добавьте приведенные выше параметры также в шаблон расширенной конфиденциальности.

3. [Необязательный] **Пользовательские параметры:** Настройте свои параметры для включения в постбэк.
4. Используйте предварительный просмотр шаблона постбэка, чтобы проверить, что все настроено правильно.
5. Нажмите **Сохранить**.

## Постбэки для расширенной конфиденциальности и постбэки SKAN

Постбэки для расширенной конфиденциальности и постбэки SKAN можно настроить только после создания ссылки атрибуции и постбэка по умолчанию.

**Для управления постбэками:**

1. Выберите тип постбэка:
   * Постбэк для <Anchor target="_blank" href="/partners/ru/docs/advanced-privacy-guide-postback-macros-for-ad-networks">расширенной конфиденциальности</Anchor> .
   * Постбэк <Anchor target="_blank" href="/partners/ru/docs/skan-integration-guide-for-ad-networks">SKAdNetwork</Anchor>.
2. Активируйте конструктор.
3. **[Только для конфигурации постбэка SKAdNetwork]** Введите свой идентификатор SKAdNetwork. Это поле является обязательным. Конфигурацию невозможно сохранить без действительного идентификатора.
4. Введите **адреса конечных точек.** Это конечные точки, на которые отправляются постбэки. Введите действительные URL-адреса для установок и/или внутренних событий приложения.
5. Добавьте параметры постбэка:

   * **Имя параметра**: Экранное имя параметра AppsFlyer.
   * **Получаемый вами параметр**: Соответствующий получаемый параметр на вашей стороне.
   * **Значение параметра** (доступно для некоторых параметров): выберите формат значения. Например, «true/false» или «1/0» для логических значений.
   * **Установка**: установите флажок, чтобы включить параметр в постбэк установки.
   * **Внутреннее событие приложения**: установите флажок, чтобы включить параметр в постбэк внутреннего события приложения.

   Список <Anchor target="_blank" href="/partners/ru/docs/skan-integration-guide-for-ad-networks#получение-данных-от-appsflyer">макросов для постбэков SKAdNetwork</Anchor>

   Полный список <Anchor target="_blank" href="/partners/ru/docs/advanced-privacy-guide-postback-macros-for-ad-networks#advanced-privacy-postback-specification">макросов для постбэков в режиме расширенной конфиденциальности</Anchor>.

   <div id="important-2" />

   > 🚧 **Важно!**
   >
   > * Чтобы включить постбэки с отказом об установках или внутренних событиях, добавьте следующие параметры в шаблон постбэков по умолчанию:
   >   * `отклонено`
   >   * `причина блокировки`
   >   * `подпричина блокировки`
   >   * `значение причины блокировки`
   > * Чтобы включить постбэки с отказом для расширенной конфиденциальности, вы должны сначала добавить приведенные выше параметры к [постбэку по умолчанию.](/docs/self-serve-integration-management-for-ad-networks#постбэк-по-умолчанию)
   > * Когда указанные выше параметры добавляются как в постбэк по умолчанию, так и в постбэк расширенной конфиденциальности (если она включена), включаются постбэки с отказом для установок и событий в приложении.

6. [Необязательно] **Пользовательские параметры:** Настройте свои параметры для включения в постбэк.
7. Используйте предварительный просмотр шаблона постбэка, чтобы проверить, что все настроено правильно.
8. Нажмите **Сохранить**.  
   Обратите внимание, что при сохранении постбэка изменения сразу вступают в силу.

В случае возникновения каких-либо проблем свяжитесь с нами с помощью <Anchor target="_blank" href="https://af-static-content.s3.eu-west-1.amazonaws.com/marketplace/static/logo/Help_GIF_Final-min.gif">виджета помощи партнерам</Anchor>.
