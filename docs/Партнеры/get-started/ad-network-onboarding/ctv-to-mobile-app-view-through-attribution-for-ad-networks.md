> **At a glance:** Сопоставляйте установки мобильных приложений с рекламой, просмотренной на устройствах connected TV (CTV).

<div id="ctv-to-mobile-app-attribution-for-ad-networks" />

## Атрибуция CTV для мобильных приложений для рекламных сетей

Используя меж-платформенные URL-адреса показов AppsFlyer, вы можете оптимизировать установки мобильных приложений через рекламу, показываемую на CTV. Несколько установок в одном домохозяйстве могут быть приписаны одному и тому же показу рекламы на CTV.

![Схема процесса атрибуции из CTV в мобильное приложение](https://files.readme.io/401bcb083e1cc618794cb302668f7271cf825a5a6045ff10055e0164baf423a1-19774176963473.jpg)

Для атрибуции просмотров с CTV в мобильное приложение используется <Anchor target="_blank" href="/marketers/ru/docs/set-up-cross-platform-links-for-multi-device-campaigns#setup">URL-адрес показов OneLink</Anchor>, основанный на меж-платформенном шаблоне OneLink, созданном рекламодателями. Это позволяет рекламодателям объединять несколько приложений с разных платформ (например, приложения для Android и iOS), используя единый URL-адрес.

Когда пользователи просматривают рекламу на CTV, отправьте в AppsFlyer URL-адрес показа в реальном времени. 

Пример URL-адреса:

```
https://impressions.onelink.me/{template_id}?pid=__media_source__&af_xplatform=true&af_xplatform_vt_lookback=24h&af_siteid=__CSITE__&c=__CAMPAIGN_NAME__&af_channel=__PLACEMENT__&af_c_id=__CAMPAIGN_ID__&af_adset=__AID_NAME__&af_adset_id=__AID__&af_ad=__CID_NAME__&af_ad_id=__CID__&af_source_platform=__source_platform__&af_source_device_category=__device_category__&af_ad_type=__CTYPE__&af_ip=__IP__&af_ua=__UA__&redirect=false
```

AppsFlyer отправляет вам постбэки после каждой конверсии.

> 📘 **Note**
>
> Эта функция доступна только для уполномоченных партнёров. Если вас заинтересовала эта возможность, свяжитесь с вашим менеджером по развитию партнёрских отношений.

<Accordion title="Настройте атрибуцию из CTV в мобильное приложение">

**Чтобы настроить атрибуцию просмотров с CTV в мобильное приложение с рекламодателем**:

1. Убедитесь, что вы <Anchor target="_blank" href="/partners/ru/docs/getting-started-onboarding-guide-for-ad-networks">интегрированный партнер AppsFlyer</Anchor>, что у вас правильно настроены постбэки и что вы [протестировали интеграцию CTV с мобильным приложением](/docs/ctv-to-mobile-app-view-through-attribution-for-ad-networks#test-partner-integration) в AppsFlyer.
2. Убедитесь, что URL-адрес содержит [обязательные параметры](/docs/ctv-to-mobile-app-view-through-attribution-for-ad-networks#parameters), а также любые другие нужные вам параметры.
3. Отправьте в AppsFlyer IP-адрес пользователя и его пользовательский агент. Эти данные необходимы для атрибуции просмотров с CTV на мобильное приложение. Они могут быть отправлены либо:
   1. Как параметры `af_ip` и `af_ua` в URL-адресе показа.
   2. Как параметры `<X-Forwarded-For>` и `<User-Agent>` в заголовках запроса.

</Accordion>

<Accordion title="Тестирование интеграции партнера">

**Чтобы протестировать атрибуцию просмотров с CTV на мобильное приложение**:

1. Используйте следующие тестовые приложения: com.appsflyer.android.deviceid и id1192323960
2. Свяжитесь с командой Partner Solutions AppsFlyer, чтобы получить тестовый URL. Для этого войдите в [панель партнера](https://hq1.appsflyer.com/auth/login) и в верхнем меню нажмите **Справка** > **Связаться с нашей командой**.
   * Пример URL-адреса: `https://impressions.onelink.me/dfHa?pid=partner_int&c=test_1&af_xplatform=true&af_xplatform_vt_lookback=24h&af_ip=MACRO&af_ua=MACRO&redirect=false`
3. Убедитесь, что идентификатор партнера в параметре `pid` указан верно.
4. Введите ваш IP-адрес в параметре `af_ip`.
5. Введите ваш пользовательский агент в параметре `af_ua`.
6. Введите URL-адрес в браузере настольного компьютера.
7. На мобильном устройстве перейдите в магазин приложений, загрузите, установите и запустите приложение.
8. Новая установка появляется в AppsFlyer вместе с соответствующим постбэком. Если вы не видите установку или не получаете постбэк, обратитесь в команду поддержки Partner Solutions.

</Accordion>

<Accordion title="Параметры">

Следующие параметры используются для предоставления данных атрибуции и измерения рекламодателям.

| Параметр | Обязательно | Описание |
| --- | --- | --- |
| template\_id | ✓ | Идентификатор <Anchor target="_blank" href="/marketers/ru/docs/create-a-onelink-template">шаблона OneLink</Anchor>. Шаблон содержит основные настройки прогнозирования для приложений рекламодателя и является основой для создания других ссылок. Примечание: никогда не кодируйте значение `template_id`. |
| pid | ✓ | Идентификатор партнера, назначаемый AppsFlyer медиа-источнику (рекламной сети), размещающему рекламу. |
| af\_xplatform | ✓ | <ul><li>От 1 до 72 часов, в зависимости от параметра окна атрибуции . .</li><li>Значения: true/false</li></ul> |
| af\_xplatform\_vt\_lookback | - | Настраиваемое окно, которое указывает количество часов после показа, в течение которых установка приложения может быть отнесена к показу. Доступные значения параметров: 1–72 ч. (часов). Ценность, значение по умолчанию — 24 часа. |
| af\_ip | ✓ | <ul><li>IP-адрес устройства CTV, на котором отображается реклама.</li><li>Если IP-адрес не передается в URL-адресе, его необходимо передать в заголовках запроса, чтобы AppsFlyer мог выполнить атрибуцию CTV к мобильному приложению.</li></ul> |
| af\_ua | ✓ | <ul><li>Пользовательский агент устройства CTV, на котором отображается реклама.</li><li>Если пользовательский агент не передается в URL-адресе, его необходимо передать в заголовках запроса, чтобы AppsFlyer мог выполнить атрибуцию CTV к мобильному приложению.</li></ul> |
| af\_source\_platform | - | <ul><li>Список значений для представления операционной системы, на которой происходит показ.</li><li>ID аккаунта рекламодателя в рекламной сети<ul><li>Android</li><li>ios</li><li>тизен</li><li>WebOS</li><li>SmartCast</li><li>Roku</li><li>Windows Phone</li><li>VIDAA</li><li>PlayStation</li><li>веб-сайт</li></ul></li></ul> |
| af\_source\_device\_category | - | <ul><li>Список значений, представляющих тип устройства, на котором происходит показ.<ul><li>ТВ</li><li>мобильный\_телефон</li><li>компьютер</li><li>планшет</li><li>приставка</li><li>игровая\_консоль</li><li>неизвестная\_категория\_устройства</li><li>медиа\_плеер</li></ul></li></ul> |

Другие параметры, которые можно добавить в URL-адрес, приведены в <Anchor target="_blank" href="/marketers/ru/docs/about-link-structure-and-parameters">статье о структуре и параметрах ссылки атрибуции</Anchor>.

</Accordion>

<Accordion title="Характеристики и ограничения">

| Специфика | Description(Описание) |
| --- | --- |
| Окно атрибуции | От 1 до 72 часов, в зависимости от параметра окна ретроспективы `af_xplatform_vt_lookback`. |
| Обязательный | <ul><li>Реатрибуция: Поддерживается для межплатформенного перехода на мобильное приложение. Не для других платформ.</li><li>Повторное вовлечение: Не поддерживается</li></ul> |
| Метод атрибуции | Атрибуция по просмотрам с использованием вероятностного моделирования (IP-адрес) |
| Атрибуция домохозяйств | Поддерживается. Несколько установок в одном домохозяйстве могут быть атрибутированы одному и тому же показу рекламы на CTV. |
| Тестирование интеграции партнера | Недоступно для рекламных сетей с высоким уровнем мошенничества среди мобильных приложений или связанных с другими отмеченными источниками медиа. |

</Accordion>
