> **Краткий обзор:** обратитесь в поддержку AppsFlyer для партнеров через чат-бот Partner Assistant, чтобы устранить неполадки, открыть тикет в поддержку или получить рекомендации по продукту.

## Информация о компании

Чатбот «Помощник партнера» направляет ваши запросы в соответствующую команду по вопросам, связанным с приложением, рекомендациями по продукту и технической поддержкой. Шаги чатбота подскажут вам, что нужно сделать для получения точной помощи, сокращая потребность в дополнительной информации.

**Чтобы открыть чатбот «Помощник партнера»:**

1. В верхнем меню выберите **Помощь** > **Связаться с нашей командой**. Откроется чатбот «Помощник».  
   <Image alt="contact-your-team2.jpg" src="https://files.readme.io/3efd3a509befa24c89182f382187025693b02cdd81709e112bc6cd296f90e0dc-26191280580625.jpg" width="257px" />

2. Выберите **тип тикета** из списка и заполните всю информацию.

<Image alt="partner-facing.png" src="https://files.readme.io/06f13de849f08fe9df084385fd96cdf9aa2bb1f414c235e991a1dfb24a301a32-50490825210129.png" width="720px" />

**Примечание:** у агентств нет варианта «Проблемы интеграции или обновления».

3. Кликните **Отправить**.

## Просмотр заявок партнеров

Открытые вами заявки партнеров доступны в вашей переписке по электронной почте со службой поддержки AppsFlyer. Вы можете искать заявки, просматривать их и проверять их статус.
