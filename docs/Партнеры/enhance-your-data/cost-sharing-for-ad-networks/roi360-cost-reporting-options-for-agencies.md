## Отчетность о стоимости для агентств

Рекламодатели используют AppsFlyer в качестве источника достоверной информации об окупаемости инвестиций, выставлении счетов и принятии решений о распределении маркетингового бюджета. Для этого им нужно иметь всю информацию о стоимости на одной платформе. ROI360, премиум-решение AppsFlyer, позволяет рекламодателям и агентствам собирать данные о стоимости через API и просматривать их с помощью дэшбордов AppsFlyer и инструментов отчетности. 

Данные о стоимости можно агрегировать одним из следующих способов: 

* **Cost API**: AppsFlyer извлекает данные у партнеров
* **Затраты по клику:** Сети сообщают о расходах при каждом клике по ссылке атрибуции

В следующей таблице перечислены возможности агрегирования затрат, доступные с ROI360 и без него.

| Вариант | Требуется подписка на ROI360 | Описание |
| --- | --- | --- |

(Для SRN это включает клики и показы.)</li><li>Поддерживает все модели затрат</li><li>Точность</li><li>Частота обновления данных: 6 раз в день, каждые четыре часа.</li></ul> |
| <Anchor target="_blank" href="/partners/ru/docs/cost-reporting-on-the-attribution-link-for-ad-networks">Затраты по клику</Anchor><br /><br />(в ссылке атрибуции) | Ни один | <ul><li>Агентства передают CPI, значение и валюту стоимости по ссылке атрибуции.
