> **Краткий обзор.** Сравните методы предоставления данных о расходах, доступные рекламным сетям — партнерам AppsFlyer.

<div id="sharing-cost-with-appsflyer-and-advertisers" />

## Обмен данными о расходах между AppsFlyer и рекламодателями

Рекламодатели используют AppsFlyer в качестве источника достоверной информации об окупаемости инвестиций, выставлении счетов и принятии решений о распределении маркетингового бюджета. Чтобы сети были видны на дэшборде, им необходимо делиться данными о расходах с AppsFlyer. Сети, в которых нет данных о расходах, отображаются в нижней части списка на дэшборде AppsFlyer.

Рекламные сети предоставляют данные о расходах в AppsFlyer, используя любой из следующих способов: 

* **InCost API**: Отправка данных в AppsFlyer
* **Cost API**: AppsFlyer извлекает данные
* **Импорт данных о расходах**: Файлы данных о расходах загружаются или отправляются в AppsFlyer
* **Затраты по клику:** Сети сообщают о расходах при каждом клике по ссылке атрибуции

<div id="cost-badge-for-ad-networks" />

### Значок затрат для рекламных сетей

<Image align="center" alt="CostBadge.jpg" src="https://files.readme.io/6b660b68b932802f7982a3beb3a155ecc350de1b4cb3baede6e84ef0d704388c-360011247338.jpg" />

* На <Anchor target="_blank" href="/marketers/ru/docs/partner-integrations#partner-details-and-performance">странице сведений о партнерах</Anchor> отображается значок затрат, указывающий партнеров, использующих InCost или Cost API.
* Значок подтверждает, что партнер является экономически состоятельным.
* Внутренняя аналитика и обширные опросы пользователей показывают, что рекламодатели всегда ищут новых партнеров. Те, у кого есть значок затрат, с большей вероятностью будут выделяться, поскольку рекламодатели хотят оценить эффективность своей маркетинговой деятельности на основе анализа рентабельности инвестиций.

### Варианты отчетности о расходах, доступные рекламным сетям

| Вариант | Получение значка затрат | Характеристики варианта |
| --- | --- | --- |
| <Anchor target="_blank" href="/partners/ru/docs/incost-api-for-ad-networks">InCost API</Anchor> | ✓ | Рекламная сеть полностью определяет, когда настраивать отчетность через InCost.<br /><br />InCost имеет следующие функции:<ul><li>Поддерживает все модели затрат</li><li>Точность и надежность</li><li>Полностью автоматизировано</li><li>Что контролирует партнер рекламной сети:<ul><li>Схема загрузки данных</li><li>Когда загружать (актуальность данных)</li></ul></li><li>Рекламодатель предоставляет партнеру разрешение на загрузку данных о расходах на дэшборде AppsFlyer.</li></ul>**Ограничение**:<br /><br />Аккаунты агентств в AppsFlyer не поддерживаются. |
| Cost API | ✓ | <ul><li>Поддерживает все модели затрат</li><li>Точность</li><li>Партнер сохраняет некоторый контроль над своими данными о расходах в AppsFlyer</li><li>Поддерживает затраты для аккаунтов агентств в AppsFlyer</li><li>Рекламодатели предоставляют учетные данные своих партнеров на дэшборде AppsFlyer</li><li>Частота обновления данных: 6 раз в день, каждые четыре часа</li></ul>**Ограничение**:<br /><br />Интеграция зависит от приоритетов AppsFlyer. |
| <Anchor target="_blank" href="/partners/ru/docs/cost-import-for-ad-networks">Импорт данных о расходах</Anchor><br /><br />(загрузка файла) | Нет | <ul><li>Партнер рекламной сети:<ul><li>Загружает данные вручную, если нет инженерных ресурсов для автоматизации</li><li>Контролирует, когда загружать данные</li><li>Сохраняет некоторый контроль над данными о расходах в AppsFlyer</li><li>Интеграция осуществляется для каждого приложения. Рекламодатель предоставляет партнеру разрешение на загрузку данных о расходах на дэшборде AppsFlyer.</li><li>Сопоставление с данными атрибуции основано на названии кампании (а не на идентификаторе кампании)</li></ul></li></ul>**Ограничение**:<ul><li>Аккаунты агентств в AppsFlyer не поддерживаются</li><li>Риск сбоя при автоматической загрузке по электронной почте</li></ul> |
| <Anchor target="_blank" href="/partners/ru/docs/cost-reporting-on-the-attribution-link-for-ad-networks">Затраты по клику</Anchor><br /><br />(в ссылке атрибуции) | Нет | <ul><li>Быстрое решение для кампаний CPI</li><li>Почти в реальном времени</li><li>Затраты по клику могут быть менее точными, если рекламодатель использует SKAdNetwork</li></ul>**Ограничение**:<ul><li>Ограничено моделью затрат CPI</li><li>Если по ссылке отправлены неверные данные, их нельзя изменить задним числом</li><li>Ретаргетинг не поддерживается</li><li>Затраты, предоставленные по клику, отображаются на дэшборде SkadNework, если доступны</li></ul> |
