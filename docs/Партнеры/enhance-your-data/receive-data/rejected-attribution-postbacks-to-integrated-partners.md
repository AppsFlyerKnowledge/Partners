> **Краткий обзор:** Интегрированные партнеры получают постбэки по отклоненным установкам и in-app событиям из-за мошенничества или несоблюдения правил проверки.

<div id="rejected-attribution-postbacks-relating-to-fraud-and-validation-rules" />

## Отклоненные атрибуционные постбэки, связанные с мошенничеством и правилами проверки

**Терминология**:

* **События мошенничества:** установки и in-app события, заблокированные Protect360
* **Несоответствующие события**: установки и in-app события, которые не соответствуют правилам проверки
* **Отклоненные события**: События мошенничества и события несоблюдения правил проверки
* **Исправленная атрибуция установки:** Идентифицированная и заблокированная взломанная установка, атрибуция которой впоследствии исправлена и приписана подлинному медиа-источнику.

**Постбэки**

* Интегрированные партнеры получают постбэки отклоненных событий в реальном времени.
* Для in-app событий с исправленной атрибуцией установок не предусмотрены постбэки мошеннических событий.
* Отклоненные постбэки событий отправляются на указанный партнером конечный адрес как для установок, так и отклоненных событий, с дополнительными параметрами:  
  * Причина блокировки
  * Подпричина отклонения
  * Отклонено
  * Значение причины отклонения (если доступно). Например: `reject_reason=site_blacklist&reject_reason_value="1123456"&is_rejected=1`

В следующей таблице перечислены причина отклонения, значение причины отклонения и объяснение причины отклонения:

| Причина отклонения | Значение причины отклонения | Пользователь может настроить | Объяснение |
| --- | --- | --- | --- |
| ctit\_аномалии | Измеренное время от клика до установки в секундах | **X** | Аномалии CTIT — это клики, заблокированные из-за необоснованного CTIT (время от клика до установки). |
| store\_install\_validation | Н/Д | **X** | Установки, не прошедшие проверку в магазине приложений |
| черный список сайтов | Идентификатор сайта | **X** | Установки с идентификаторов сайтов, которые были заблокированы AppsFlyer из-за высокой плотности мошеннической активности. Определено нашими внутренними алгоритмами. |
| боты | Н/Д | **X** | Заблокированные попытки установки, выполненные ботами |
| клик-флуд | Идентификатор сайта или пусто | **X** | Установки из кластеров, заблокированных AppsFlyer из-за большого числа установок с высоким CTIT и низким коэффициентом конверсии. |
| поведенческие\_аномалии | Н/Д | **X** | Поведенческие аномалии, связанные с мошенничеством при установке, блокируются из-за непоследовательного и ненормального поведения после установки. |
| перехват\_установки | Н/Д | **X** | Перехват установок, приписываемый кликам, блокируется на основе необоснованного времени между кликом и установкой, согласно API сервера Google Play. |
| недействительный\_отпечаток\_пальца | Названия правил или пусто | ✓ | Правило, заданное клиентом. |
| перехват\_проверки | Названия правил | ✓ | Правило, заданное клиентом. |
| ai\_layer | Н/Д | **X** | Модели ИИ используются для анализа больших объемов данных, что помогает выявлять мошенничество с устройствами и установками. |

<div id="reject-reasons-for-in-app-events" />

#### Причины отклонения событий в приложении

| Причина отклонения | Значение причины отклонения | Объяснение |
| --- | --- | --- |
| Наследуется от install | Наследуется от install | Первоначальная установка распознана как фейк на основании <Anchor target="_blank" href="/marketers/ru/docs/protect360-raw-data-reports#причины-блокировки">установить</Anchor> или<Anchor target="_blank" href="/marketers/ru/docs/protect360-raw-data-reports#причины-блокировки"> чёрного списка</Anchor> уровня причины |
| inapps\_bots | поддельные\_параметры\_устройства | Алгоритм AppsFlyer обнаруживает мошенничество |
| проверка\_inapps | invalid\_event\_name | На основе запрошенного или вручную заданного правила проверки |
| проверка\_inapps | invalid\_event\_value | На основе запрошенного или вручную заданного правила проверки |
| проверка\_inapps | Имена правил | На основе вручную заданных правил |

<div id="important" />

> 🚧 **Важно!**
>
> * Чтобы различать постбэки для допустимых событий и отклонённые постбэки, необходимо настроить <Anchor target="_blank" href="/partners/ru/docs/postback-macros-for-ad-networks#макросы-установки-внутренние-события-приложения-и-отклоненные-события">макросы отклонённых постбэков</Anchor>.
> * Чтобы включить отклонённые постбэки для Advanced Privacy, сначала добавьте следующие параметры к <Anchor target="_blank" href="/partners/ru/docs/self-serve-integration-management-for-ad-networks#постбэк-по-умолчанию">постбэку по умолчанию</Anchor>:
>   * `is-rejected`
>   * `blocked-reason`
>   * `blocked-sub-reason`
>   * `blocked-reason-value`
> * Когда указанные выше параметры добавлены как к постбэку по умолчанию, так и к постбэку Advanced Privacy, включаются отклонённые постбэки для установок и внутренних событий приложения.
