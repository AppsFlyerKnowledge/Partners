> **На взгляд:** Партнеры по API могут использовать свой API токен для доступа к данным рекламодателя, когда рекламодатель разрешил позволяет им извлекать метрики производительности из платформы.

<div id="api-token-permissions" />

## Разрешения токена API

<Image align="center" alt="api-access-permissions.jpg" src="https://files.readme.io/7961394cb39cf1e6f85d77cd732183edea5fb1408c220ca05b23ae7bbb50138e-23701010316689.jpg" width="439px" />

Рекламодатели могут предоставить следующие разрешения уровня приложения:

| Тип разрешения                     | Инструмент отчетности                                                                                                                                                                                                                                                                      | Ограничения                                                               |
| ---------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------- |
| Отчёт об агрегированных аналитиках | <Anchor target="_blank" href="/marketers/docs/cohort-analytics-via-data-locker">Когортные аналитические данные через DataLocker</Anchor>                                                                                                                                                   | Данные кампании X Рекламы не доступны партнерам API из-за их ограничений. |
| Отчёт о SKAN                       | <ul><li><Anchor target="_blank" href="/marketers/docs/skan-aggregated-performance-report-api">СКАН отчёт об эффективности</Anchor></li><li><Anchor target="_blank" href="/marketers/docs/skan-aggregated-postback-arrival-date-api">СКАН совокупная отчетность postback</Anchor></li></ul> | --                                                                        |

<div id="considerations" />

### Соображения

- **Ракурс рекламодателя**
  - Рекламодатели могут предоставить разрешения партнерам API, указанные в предыдущей таблице.
- **Ракурс партнера**
  - Извлечь данные по API. **Примечание**: Безопасность реализована с помощью аутентификации<Anchor target="_blank" href="/marketers/docs/managing-appsflyer-tokens">токена</Anchor> в панели управления AppsFlyer . Один и тот же токен действителен для всех приложений и рекламодателей.
  - Получение данных через Data Locker
  - Рекламодатели могут отозвать разрешения для доступа к данным своего приложения. Это не повлияет на ваши учетные данные партнера.

<Accordion title="Granting access to the partner">

<div id="important" />

> 🚧 **Важно**
>
> **предупреждение**
>
> - Тип разрешений позволяет партнерам получить доступ к данным, включая трафик, предоставленный другими партнерами, и органические данные.
> - Не делитесь вашим токеном с партнерами.

**Чтобы предоставить партнеру доступ к API:**

1. В AppsFlyer, из бокового меню, выберите **Сотрудник** > **Интегрированные партнеры**.
2. Ищите партнера и выберите его.
3. Нажмите на **Настроить интеграцию**. Вы будете перенаправлены на страницу настройки интеграции.
4. Во вкладке **доступ к API** включите одно или несколько разрешений. Выбрать из:
   - **Совокупная аналитическая отчетность**
   - **Отчетность SKAdNetwork** (для iOS приложений, не относящихся к Data Locker)
5. Нажмите на **Сохранить API**.
6. Сообщите партнеру, который вы включили необходимый доступ к API.

</Accordion>
